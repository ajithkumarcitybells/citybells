## 🔧 Troubleshooting

### Problem: mongosh command not found

**Solution:** Install MongoDB Community Edition
- Windows: Download from https://www.mongodb.com/try/download/community
- Or use the Node.js script: `node verify-vehicle-types.js`

### Problem: Cannot connect to MongoDB

**Check:**
1. Is MongoDB running? `mongosh`
2. Is connection string correct?
3. Database exists? `use city_serve_hub`

### Problem: Insertion fails with validation error

**Most common:** String vs Number issue

❌ **Wrong:**
```json
{
  "baseFare": 20,           // Number
  "perKmRate": 10          // Number
}
```

✅ **Correct:**
```json
{
  "baseFare": "20.00",      // String
  "perKmRate": "10.00"      // String
}
```
